# OurWatchList. logo (concept A, two frames)

Colors: #FFFFFF and #030303 only.

svg/  icon, horizontal, stacked, app (rounded square), wordmark; each -dark (white on near-black) and -light (near-black on white). Wordmark is outlined Oswald 600, no font needed.
png/  app-dark at 16, 32, 48, 180, 192, 512 plus horizontal lockups at 1024px.
favicon.svg, favicon.ico  browser tab icon.

Usage in <head>:
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="icon" href="/favicon.ico" sizes="48x48">
  <link rel="apple-touch-icon" href="/png/app-dark-180.png">

Nav logo (dark theme, 24px tall): svg/horizontal-dark.svg has built-in padding, so for exact 24px height use the icon + wordmark without padding, or crop with the viewBox.
